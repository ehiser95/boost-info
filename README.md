# Boost Info
A clean, compact list of stat boosts and potion timers (overload, smelling salts, prayer regeneration, prayer enhance, divine potions), with a red warning before each overload/salts refresh and an optional fade when a timer runs low.

## Credits

Timer and buff detection (cannon, freezes, teleport cooldowns, Arceuus and Lunar spells, ToA supplies, boss buffs, burn damage, Fight Caves / Inferno and more) is adapted from RuneLite's built-in Timers & Buffs plugin (BSD-2).
